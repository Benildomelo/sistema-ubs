# 🏥 Sistema UBS - Sistema de Agendamento

Sistema completo para agendamento em Unidades Básicas de Saúde, com funcionalidades para pacientes e profissionais.

## 🚀 Como Usar

Acesse: [https://seuusuario.github.io/ubs-system](https://seuusuario.github.io/ubs-system)

## 🎯 Funcionalidades

### Para Pacientes
- ✅ Agendamento de consultas
- ✅ Cancelamento e reagendamento
- ✅ Histórico de consultas
- ✅ Localização de UBSs
- ✅ Perfil do usuário

### Para Profissionais
- ✅ Dashboard com agenda
- ✅ Gestão de prontuários
- ✅ Prescrição de medicamentos
- ✅ Solicitação de exames
- ✅ Cadastro de pacientes

## 🛠️ Tecnologias

- **Frontend:** HTML5, Tailwind CSS, JavaScript
- **Armazenamento:** LocalStorage
- **Ícones:** Material Symbols
- **Deploy:** GitHub Pages

## 📝 Importante

- Este é um sistema de **demonstração**
- Os dados são salvos **apenas no seu navegador**
- Funciona totalmente offline
- Ideal para testes de usabilidade
